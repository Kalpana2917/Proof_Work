01. Project Overview

ProofWork is an MCA-level Relational Database Management System (RDBMS) project built around the concept of trustworthy digital work records.

In the freelance ecosystem, portfolios and work claims can be difficult to evaluate consistently. ProofWork proposes a structured relational approach to connect project records, work submissions, reviews and transaction evidence into an organized professional experience record.

The project combines database fundamentals with a modern, startup-inspired product concept.

02. The Problem

Freelance portfolios often depend on information shared by freelancers themselves. Employers and clients may find it difficult to assess the authenticity, context and quality of claimed work experience.

Key Challenges

- Unstructured freelancer experience records.
- Difficulty organizing project history.
- Limited connection between work submissions and feedback.
- Lack of a unified record of project milestones.
- Difficulty maintaining structured work-related evidence.

---

03. Our Proposed Solution

ProofWork introduces a structured database model to connect freelancers, organizations, projects, applications, milestones, submissions, reviews and transactions.

The proposed system organizes work-related records into interconnected entities, making project information easier to manage, retrieve and review.

04. How ProofWork Works

The proposed workflow represents how project-related information can be organized within the system.

1. User Registration — Users and organizations are represented in the database.
2. Project Creation — Project details and requirements are recorded.
3. Application — Freelancers submit applications for projects.
4. Work Submission — Work-related submissions are stored.
5. Milestone Tracking — Project milestones are organized.
6. Review & Feedback — Reviews are associated with project work.
7. Transaction Records — Transaction-related information is maintained.
8. Verified Experience Records — Relevant work records are organized into the VerifiedExperience entity.

08. Database Integrity & Automation

ProofWork uses relational database principles to maintain structured and consistent data.

Database Mechanisms

- Foreign Keys: Connect related entities.

14. Project Limitations

- Real-world identity verification is not integrated.
- Live payment processing is not implemented unless separately integrated.
- External freelancer platforms are not connected.
