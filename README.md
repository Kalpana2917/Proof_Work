<h2 align="center">WHY PROOFWORK?</h2>

<table>
<tr>
<td width="50%" valign="top">

<h3>⚠️ The Problem</h3>

Freelance work history can be difficult to evaluate when project records, skills and feedback are scattered across platforms.

<ul>
<li>Unstructured work records</li>
<li>Difficulty evaluating experience</li>
<li>Scattered project information</li>
<li>Limited structured feedback</li>
</ul>

</td>

<td width="50%" valign="top">

<h3>💡 Our Solution</h3>

ProofWork organizes work-related information through a structured relational database.

<ul>
<li>Organized freelancer profiles</li>
<li>Skill and project relationships</li>
<li>Application and submission records</li>
<li>Reviews and verified experience</li>
</ul>

</td>
</tr>
</table>

<h2 align="center">🚀 GETTING STARTED</h2>

<p align="center">
  <i>Set up the ProofWork database locally</i>
</p>

<h3>Prerequisites</h3>

- MySQL Server
- MySQL Workbench (recommended)

<h3>Installation</h3>

<ol>
<li>Clone this repository.</li>
<li>Open MySQL Workbench and connect to your MySQL server.</li>
<li>Open the SQL schema file from the <code>database</code> folder.</li>
<li>Execute the schema script to create the database tables.</li>
<li>Run the available SQL data scripts, if provided, to populate sample data.</li>
</ol>
